# Dulciano — Fracture Sounds Reference

Updated: 2026-09-08

Series: **Main Catalog**

Official product page: https://fracturesounds.com/product/dulciano/

## 1. Summary

- Grand piano struck with dulcimer hammers; Single notes, velocity-triggered one-shot rolls and CC1/aftertouch sustained rolls; up to 12 RR.
- Kontakt Player / NKS product in the current Fracture Sounds ecosystem unless otherwise noted by the product page.

## 2. Performance / articulation controls

| Control / feature | Function |
|---|---|
| Velocity | Dynamics; high velocities trigger one-shot rolls |
| CC1 / Mod Wheel | Sustained roll intensity/activation |
| Aftertouch | Can control sustained rolls |
