## Dulciano note

- `Dulciano` is **not treated as a legacy/discontinued product** here. It is currently sold by Fracture Sounds and appears in the current Everything Bundle.
- It is the hammered-grand-piano instrument: single notes, velocity-triggered one-shot rolls, sustained rolls via CC1/Mod Wheel or aftertouch, up to 12 round robins.
