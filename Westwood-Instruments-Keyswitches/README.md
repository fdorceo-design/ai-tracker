## Important mapping rule

- Newer Westwood instruments expose `ALL KEYSWITCHES` and a movable `KEYSWITCH POSITION` setting.
- This means factory KS locations are not necessarily permanent.
- AI Tracker references should therefore prefer articulation names plus the installed mapping, with exact MIDI notes recorded only when fixed/confirmed.
