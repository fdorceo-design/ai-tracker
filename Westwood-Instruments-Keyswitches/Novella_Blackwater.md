# Novella Blackwater — Westwood Instruments Reference

Updated: 2026-09-08

- Category: **Scoring Toolkit**
- Platform: **Kontakt Player 6.6.1+**

## 1. Summary

- Western/Americana-inspired scoring toolkit; strings, guitars and atmospheric material; Motion system for tempo-synced dynamics.

## 2. Performance / articulation reference

| Control / feature | Behavior |
|---|---|
| Motion | tempo-synced automated dynamics on string ensemble |
| Wends | loose fingerstyle nylon-guitar performances |
| Feature | Evergreen-style articulation/sound switching where provided |
| Feature | CC11 Expression / CC1 Dynamics follow Westwood framework where applicable |

## 3. Westwood keyswitch policy

- Exact keyswitch MIDI-note numbers are only recorded when the official manual explicitly supplies them.
- In Westwood's newer Kontakt framework, keyswitches can be disabled globally and their keyboard position can be shifted by the user.
- Therefore an installed instrument's current mapping takes precedence over any factory-location reference.
- No KS note number has been inferred from screenshots or from another Westwood product.

## 4. Common controller behavior

- **CC11**: Expression on the documented newer Westwood framework.
- **CC1 / Mod Wheel**: natural recorded dynamics for articulations set to MOD or MOD+VEL.
- **Velocity**: commonly controls short, piano and percussion dynamics.
- These behaviors are articulation-editable on supported instruments and should not be treated as immutable for every patch.
