# Impact Soundworks — Full Kontakt Reference Index

Updated: 2026-09-08

Included: **34 confirmed Full-Kontakt instruments/libraries**.

Scope: products whose official Impact Soundworks requirements specify the full paid version of Kontakt and explicitly exclude Kontakt Player.

## Excluded by design

- Kontakt Player products (for example current Shreddage 3, Tokyo Scoring Strings, Kageyama Taikos, Hammer Klavier, current keyboard catalog).
- Bundles when they only duplicate individual products.
- Duduk from the Complete World Bundle, because that product is Kontakt Player compatible.

## Mapping policy

- Exact KS notes are not guessed.
- Articulation names, CC behavior, RR counts and velocity behavior are retained when official pages/manuals expose them.
- Impact Soundworks libraries with configurable articulation mapping should be treated as mapping-flexible rather than assuming one immutable global KS layout.
