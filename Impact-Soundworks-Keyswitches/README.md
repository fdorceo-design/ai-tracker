# Impact Soundworks — AI Tracker Reference Index

Updated: 2026-09-08

Reference notes for Impact Soundworks Kontakt libraries, split by
Kontakt edition requirement (these are deliberately separate sets, not
merged, since the same instrument can behave differently — or not load
at all — depending on which edition it needs).

## Sets

- [Full_Kontakt/](Full_Kontakt/README.md) — 34 products whose official
  requirements specify full paid Kontakt and explicitly exclude Kontakt
  Player, organized by category (Guitar_Bass, Orchestral, Percussion,
  Sound_Design, Vocal, World).
- [Kontakt_Player/](Kontakt_Player/README.md) — 58 products from
  Impact Soundworks' official "Kontakt Player Compatible" category,
  including bundles and free editions where they list them.

## Source policy

Official Impact Soundworks product pages/compatibility categories are
the primary source. Exact keyswitch note numbers are never invented;
libraries with configurable/remappable articulation layouts are treated
as mapping-flexible rather than assumed to have one fixed global layout.
