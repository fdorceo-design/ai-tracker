# Embertone — AI Tracker Reference Index

Updated: 2026-09-08

Reference notes for Embertone Kontakt libraries, organized by catalog
section (one subfolder per section).

## Sections

- [Current_Catalog/](Current_Catalog/README.md) — 37 independent
  instruments from the current official Embertone Instruments catalog.
  Bundles and edition duplicates (e.g. Joshua Bell Violin Essential,
  Walker 1955 Concert D Lite/Full/Complete) are consolidated into their
  base instrument's file rather than duplicated.

## Source policy

Official Embertone product/catalog pages are the primary source. Exact
keyswitch MIDI-note numbers are recorded only when explicitly published
in official Embertone documentation — Embertone often ships detailed
manuals inside the installed `Documentation`/`Extras` folder rather than
on the product page, so an installed manual should override these
summaries when it supplies exact assignments. No MIDI note number has
been guessed from keyboard colors, screenshots, or convention.
