# Blakus Cello — Embertone Reference

Updated: 2026-09-08

- Catalog status: **Current**
- Category: **Strings**
- Tier: **Paid**
- Kontakt requirement: **Kontakt Player compatible**

## 1. Summary

- Intimate Strings solo cello; true/adaptive legato, dynamic morphing, modeled vibrato, bow-position color morphing, ensemble mode.

## 2. Performance / articulation reference

- 3 legato types (Bow/Slur/Portamento); Soft/Normal/Accent attacks; Sordino/Sul Pont/Sul Tasto; Tremolo; Staccato 3 dyn 8RR; Pizzicato 4 dyn incl. Snap, 8RR.

- Exact keyswitch MIDI-note numbers are included only when explicitly published in official Embertone documentation.
- Embertone often places detailed manuals inside the installed `Documentation` or `Extras` folder.
- No MIDI note number has been guessed from keyboard colors, screenshots or convention.
