# Spitfire Solo Strings — Keyswitch & CC Reference

Kontakt startup-patch keyswitch layout for the user's current
**Spitfire Solo Strings** setup.

This reference covers the six main startup patches:

- `a - Violin (Virtuoso)`
- `b - Violin (1st Desk)`
- `c - Violin (Progressive)`
- `d - Viola`
- `e - Cello`
- `f - Bass`

The articulation names were checked against the Spitfire Solo Strings manual /
official articulation inventory and the actual Kontakt UI screenshots supplied
by the user.

## Important

- All values below are **raw MIDI Note Numbers**.
- Do **not** convert from octave names such as `C-2`, `C-1`, etc.
- In the user's current Kontakt setup, the main keyswitch bank starts at
  **MIDI Note No. 0**.
- The Kontakt articulation grid is mapped in displayed slot order:
  top row left-to-right, then bottom row left-to-right.
- Multiple supplied screenshots directly confirmed slot positions by selecting
  named articulations in Kontakt.
- Keyswitches are sticky: send the keyswitch before the musical note(s) that
  should use that articulation.
- If the Spitfire keyswitch bank is moved in Kontakt, these raw MIDI Note
  Numbers must be re-verified.

## AI Tracker usage

For a keyswitch note:

1. Identify the exact loaded Solo Strings startup patch.
2. Select the articulation from the corresponding table above.
3. Send the listed raw MIDI Note Number on the same track/channel.
4. Place the keyswitch genuinely before the musical note it should affect.
5. Do not derive the MIDI number from an octave-name convention.

Example:

```text
Loaded patch: e - Cello
Wanted articulation: Short Staccato
Keyswitch: MIDI Note No. 6
```

The keyswitch remains active until another articulation keyswitch is sent.

## Continuous controllers

The main Solo Strings interface exposes the usual performance controllers,
including:

- CC1 — Dynamics
- CC11 — Expression
- CC21 — Vibrato

These are continuous controls and are separate from the articulation
keyswitch notes above.
