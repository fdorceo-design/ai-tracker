# MODWHEEL Roundwound — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/roundwound

## 1. Library facts

- 64 Kontakt patches: Pads 10, Textures 16, Two Guitars 13, Leads 12, Bowed Guitars 5, Misfits 8.
- 2,174 multisamples, 24-bit/48 kHz, 10.07 GB core library.
- Requires full Kontakt 6.7.1 or higher.
- Textural/cinematic guitar library.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|

| Mic positions | Close/Mid/Far with separate controls and ±1 octave pitch. |
| Filters | High-pass, mid band and low-pass. |
| Step-mod | Volume rhythm modulation. |
| Scatter Box | Experimental convolution IR rack. |
