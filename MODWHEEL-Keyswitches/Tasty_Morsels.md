## 3. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Amb-DetBaSs — Mod Wheel (CC1) | Crossfades two layers; as the MW layer comes in, the original layer fades out. |
| Amb-DetBaSs — Keyswitches | Change the start point of the upper sample layer, altering sound and texture. |
| Rhy-BaSs MallEt — Mod Wheel (CC1) | Controls low-pass filter cutoff. |
| Rhy-BaSs MallEt — Arpeggiator | Dedicated arpeggiator tab exposes rhythmic/arpeggiator controls. |
