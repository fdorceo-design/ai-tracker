# MODWHEEL WaveSkimmer — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/waveskimmer

## 1. Library facts

- Dynamic pulse-machine/scoring instrument.
- Over 150 snapshot presets.
- 24-bit/48 kHz, 245 MB core library.
- Requires full Kontakt 5.6.6 or higher.
- Full automation and MIDI CC pre-assigned.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Pulse grid | 1–32 steps; resolution from 64th notes to whole notes. |
| Pitch grid | Independent two-octave pitch grid, also 64th to whole-note resolution. |
| MIDI CC | Official page states full automation/MIDI CC is pre-assigned. |

## 3. Notes

- WaveSkimmer is control/grid based; it is not primarily a conventional articulation-keyswitch instrument.
