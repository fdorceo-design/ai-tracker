# MODWHEEL The Lowdown V2 — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/the-lowdown-v2

## 1. Library facts

- 100-year-old double bass library: arco, pizzicato, ambiences, pads, impacts, kits and BPM'd rhythms.
- 24-bit/48 kHz, 6.2 GB core library (3.4 GB compressed).
- Requires full Kontakt 5.5 or higher.
- Pizz Bass: 4 velocity layers, 3 round robins.
- Extended content: 26 ambience patches, 11 impacts, 24 rhythms, 20 ShapedNoise patches.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Pizz keyswitches | Sustain, Short, Semitone Slide, 5th Slides and Harmonics. |
| Arco Mod Wheel (CC1) | 3 bowed dynamic layers are controlled by mod wheel. |
| Arco keyswitches | Staccato and Expressive. |
| Ambience Mod Wheel (CC1) | Many patches add/manipulate additional layers with mod wheel. |
| Tempo sync | Rhythm patches follow host/session BPM. |
