# MODWHEEL Angklung — The Bamboozler — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/angklung

## 1. Library facts

- 23 Kontakt patches.
- 24 tuned bamboo Angklung source instruments plus additional Bambonezler/Bamstonezler material.
- 1,570 samples, 24-bit/96 kHz; 2.58 GB core library (1.4 GB compressed).
- Requires full Kontakt 5.3.1 or higher.
- Single patches have 10 round robins for up/down playing.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Mod Wheel (CC1) | Controls the volume of the up-stroke, which plays on key release. |
| Key release | Up-stroke articulation is triggered on note release. |
| Round robin | 10 RR for both up/down playing on single patches. |

## 3. Notes

- Bamstonezler is chromatically playable; major-chord Angklung are kept in separate patches.
