# MODWHEEL The Bends — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/the-bends

## 1. Library facts

- 30 Kontakt patches.
- 750 samples, 24-bit/96 kHz; 1.4 GB core library (0.7 GB compressed).
- Requires full Kontakt 5.3.1 or higher.
- Metal gongs, cymbals, gamelan, triangles and miscellaneous metal objects played underwater.
- Includes pitch bends, underwater rhythms and hits.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Pitch / Echo / Reverb / Shaping | Patch-level sound manipulation. |
| Arpeggiator | Available in patches. |
| Stutter key | Dedicated stutter-key behavior is documented. |
| Tempo sync | Rhythmic patches are BPM'd. |
