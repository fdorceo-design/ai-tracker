# MODWHEEL Autoharp and Taishogoto — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/autoharp-and-taishogoto

## 1. Library facts

- 15 Kontakt patches total: 8 Autoharp + 7 Taishogoto.
- 10,741 multisamples, 24-bit/48 kHz, 13.47 GB core library.
- Requires full Kontakt 6.7 or higher.
- Autoharp: full/long/low/mid/high strums, major/minor/dominant-7th chords, plucked open/muted, dischord and extended sounds.
- Taishogoto: polyphonic, monophonic, performance-KS, bowed, misc and extended patches.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Keyswitches | Autoharp standard and performance keyswitch patches are provided; performance KS select strum articulations. |
| Speed | Dedicated Perf KS + Speed patches alter strum speed. |
| Mic positions | Autoharp has Near/Mid/Far mic positions with level/filter controls. |
| Taishogoto performance KS | Purple keys are performance keyswitches; green keys select drone and black key deactivates drone in the performance patches. |
| Pulse / Scatter Box | All patches include rhythmic Pulse step-mod and Scatter Box convolution processing. |
