# MODWHEEL Windpipes — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/windpipes

## 1. Library facts

- 13 Kontakt patches.
- Sources: Wooden Pipe Organ, Indian Harmonium, Bass Harmonium, Melodica, Euphonium, Bottle, Voice, Whistling, Mouth Percussion and Bugle.
- 3,103 multisamples, 24-bit/48 kHz, 3.83 GB core library.
- Requires full Kontakt 6.7.1 or higher.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Mic positions | Near and Far mic positions; both have separate controls and ±1 octave pitch. |
| Drive | Distortion amount. |
| Replika | NI delay controls. |
| Filters | High-pass, mid band and low-pass. |
| Step-mod | Volume rhythm modulation. |
| Scatter Box | Sync/non-sync/reverse/atmos/phantom convolution IR sections. |
