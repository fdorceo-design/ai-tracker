# MODWHEEL — AI Tracker Reference Index

Updated: 2026-09-08

Reference notes for MODWHEEL Kontakt libraries. Source policy: the
user's installed patch inventory plus current official MODWHEEL product
pages. **MODWHEEL libraries generally don't publish one universal
keyswitch map** — mapping is patch-specific, so exact MIDI note numbers
are only included where a product page explicitly states them; otherwise
they're intentionally left out rather than guessed.
