# MODWHEEL FEEDBACK — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/feedback

## 1. Library facts

- 27 Kontakt patches.
- 1,361 multisamples, 24-bit/48 kHz, 4.85 GB core library.
- Requires full Kontakt 5.8 or higher.
- Feedback performances range from short explosive events to long evolving textures.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Filters | High-pass, mid band and low-pass. |
| Step-mod | Volume rhythm modulation. |
| Scatter Box | Sync'd/experimental convolution IR rack. |

## 3. Notes

- This is the full FEEDBACK library; it is distinct from the free Positive Feedback patch.
- Current product page does not publish a universal KS or CC map.
