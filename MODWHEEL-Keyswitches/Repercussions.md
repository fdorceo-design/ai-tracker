## 2. Library facts

- 57 Kontakt instrument patches in the official library.
- Three main groups: Tuned, Untuned and Unusual.
- Up to 6 velocity layers, multiple articulations and up to 5 round robins.
- Three microphone positions: Near, Mid and Far; each can be transposed ±1 octave.
- Requires full Kontakt 5.8 or higher.

## 3. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Velocity | Primary articulation/dynamic selector on many percussion mappings; exact layer count varies by patch. |
| Near / Mid / Far | Independent microphone channel controls. |
| Blend | On selected patches, balances Sliced/Stretched material; tempo-sync functions use Kontakt Time Machine / Beat Machine. |
| Pulse | Rhythm step-mod acting on volume. |
| Scatter Box | Convolution IR rack with Non Sync, Sync, Reverse, Atmos and Phantoms sections. |

## 4. Notes

- Repercussions is not one global keyswitch map: mapping and articulation layout are patch-specific.
