# MODWHEEL A Psaltered Zither — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/a-psaltered-zither

## 1. Library facts

- 10 Kontakt patches and 127 snapshots.
- 24-bit/48 kHz, 3.86 GB core library.
- Requires full Kontakt 5.6 or higher.
- Built from six zithers, psaltery and other fretless folk instruments.
- Most notes use 4 round robins and at least 3 velocity levels; patches span about six octaves.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Articulation faders | Plucked, picked, bowed long/medium/short, harmonics and other layers can be mixed cumulatively. |
| Articulation enable | Unused layers can be switched off to conserve CPU. |
| Per-articulation controls | Pan, envelope and ±1 octave transpose. |

## 3. Notes

- Articulations are primarily layer/fader based rather than presented as one published global KS map.
