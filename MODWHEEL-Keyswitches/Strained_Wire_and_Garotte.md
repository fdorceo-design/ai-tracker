# MODWHEEL Strained Wire + Garotte — Reference

Updated: 2026-09-08

Source policy: current official MODWHEEL product page. Exact MIDI note numbers are not guessed when the official page does not publish them.

Official page: https://www.modwheel.co.nz/strained-wire

## 1. Library facts

- 51 Kontakt patches total.
- 18 Bowed/Plucked/Mallet patches, 6 Garotte FX patches, 27 Wilberforce Atmospheres.
- Up to 3 velocity levels and 8 round robins.
- 508 samples, 24-bit/96 kHz; 2.7 GB core library (1.8 GB compressed).
- Requires full Kontakt 5.3.1 or higher.
- Bowed/Plucked/Mallet instruments play chromatically over roughly five octaves.

## 2. Performance / control reference

| Control / feature | Behavior |
|---|---|
| Mod Wheel (CC1) | Tremolo assigned to mod wheel on Bowed/Plucked/Mallet patches; speed adjustable on front panel. |
| Mod Wheel layers | Some Wilberforce Atmospheres add additional layers via mod wheel. |
| Effects | Distortion, rotary, delay and phaser are available on relevant patches. |
