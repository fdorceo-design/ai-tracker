# Ample Sound — AI Tracker Reference Index

Updated: 2026-09-08

Keyswitch/CC references for Ample Sound bass, guitar, ukulele, and metal
libraries, each sourced from that instrument's official current Ample
Sound Main Panel Manual.

## MIDI convention

- C4 = MIDI 60
- C0 = MIDI 24
- Pitch names in the official Ample Sound manuals are retained verbatim;
  raw MIDI numbers are added for AI Tracker use.

## Source policy

Official Ample Sound manuals are the primary source. No third-party
keyswitch charts are used when the official current manual provides the
information. Where a manual doesn't give a concrete MIDI note/value, no
value has been invented — it's left generic instead.
