# Arcane Strings — Crow Hill Reference

Updated: 2026-09-08

- Catalog group: **Modern Classics**
- Free product: **No**

## 1. Summary

- 19 articulations; up to 4 dynamic layers and 7 RR. Rust/Ashen/Icebreaker/Stormbreaker longs, Strikes, Plucks, Oscillations, Breaths, Storm Trems, Arcane Shorts, Gasps.

## 2. Performance / articulation reference

- Keyswitchable articulation system; keyswitchable tempo-synced motors. Longs/oscillations use crossfaded dynamics; shorts/plucks use velocity layers.

- No note number is inferred from screenshots or assumed from another Crow Hill library.
