## Keyswitch policy

- Exact note numbers are never guessed.
- Articulation names, CC behavior, velocity behavior, RR counts and tempo-sync behavior are retained where official information is available.
- For Crow Hill libraries whose UI shows the active articulation and key-switch location, the installed plugin/manual is the final authority.
