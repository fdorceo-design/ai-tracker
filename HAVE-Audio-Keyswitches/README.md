## AI Tracker scope

- articulation / trigger-bank names
- published playable range when available
- keyswitch count and exact note numbers only when officially published
- phrase/loop versus chromatic-instrument distinction
- no mixer/reverb/mic information unless needed to determine what MIDI event should be generated
